# Quickstart: Fix Asset Statistics Refresh

## Prerequisites

- Node.js (LTS recommended)
- npm

## Setup

```bash
npm install
```

## Run the app

```bash
npm run dev
```

## Tests

```bash
npm run test:run
```

## Notes

- The app runs as a local single-page web application.
- Statistics updates can be verified by editing an asset value, observing the summary update on field blur, and confirming it reverts on cancel or failed save.
